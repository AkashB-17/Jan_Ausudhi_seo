## 3. Database Schema Verification

The SQL queries in `routes/medicines.py` were cross-referenced against the actual SQLite schema. All column names and table references match.

### Tables

| Table | Columns Used by API | Row Count |
|-------|---------------------|-----------|
| `brand_medicines` | brand_id, name, name_normalized, manufacturer_name, price, pack_size_label, type, short_composition1, short_composition2, norm_composition, norm_dosage_form, ingredient_count, incomplete_composition | 246,068 |
| `brand_components` | brand_id, seq, ingredient, strength | 356,200 |
| `pmbi_products` | drug_code, sr_no, generic_name, unit_size, mrp, group_name, norm_composition, norm_dosage_form, ingredient_count | 2,439 |
| `pmbi_components` | drug_code, seq, ingredient, strength | 2,826 |
| `match_candidates` | brand_id, drug_code, match_method, match_confidence, validation_status | 59,072 |
| `ingredient_synonyms` | *(not used by API)* | 63 |

### Key Behaviors

- **Search** uses `brand_medicines.name_normalized` with `LIKE '%' || ? || '%'` — no fuzzy/semantic/ML search.
- **Matches** are filtered to `validation_status = 'Strong'` only.
- **Compare** rejects non-Strong matches with HTTP 400.
- **Price difference** is computed as `brand_price - pmbi_mrp`, rounded to 2 decimal places, and never stored.
